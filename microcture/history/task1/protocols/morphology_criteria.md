# 任务一形态证据审查准则

制定日期：2026-10-13。状态：审查方案已制定，尚未完成逐例形态审查，尚未修改标注或启动新训练。适用范围是给定候选区间的三类分类。当前正式结果说明模型能够学习、接触输入提供增量信息；仍不足以证明已可靠识别三类生物学形态。

## 已核对的定义与来源

原论文的 OPCID 是与转录相关的操纵子尺度接触域，接触图呈方形域；CHIN 是染色体发卡；CHID 是 CHIN 的域。作者特别说明 CHID 中重叠的 CHIN 不可能全部在同一个细胞同时出现，CHID 可以反映不同细胞中替代 CHIN 的群体平均。因而，不能以“同一张图中必须同时看见多个完整发卡”作为硬性 CHID 真值规则。原研究还发现 H-NS/StpA 与 CHIN/CHID 相关，使用独立实验支持 CHIN 的存在。[原论文正文、Fig. 3/5 与 Discussion](https://www.nature.com/articles/s41586-025-09396-y)

可直接引用的原文（Discussion）：

> “CHIDs represent a population average of alternative CHINs formed in individual cells.” [原论文 Discussion](https://www.nature.com/articles/s41586-025-09396-y#Sec9)

图形解释依据见 [Fig. 3](https://www.nature.com/articles/s41586-025-09396-y/figures/3) 和 [Fig. 5](https://www.nature.com/articles/s41586-025-09396-y/figures/5)。

作者在正常 37°C WT 接触图上用 HiGlass 手工标注，第一步隐藏操纵子等轨道；CHIN/CHID 尽量多标，OPCID 仅为代表性子集。表 4/5/6 对应三类，表 7 为 CHIN 间接触；不能把表 7 的离对角线接触点当成另一个已标注 CHIN 实例。[原论文 Annotation 方法](https://www.nature.com/articles/s41586-025-09396-y#Sec17)

本地输入为课程提供的 `micro-c数据/标注数据.xlsx`；已有导出记录保留源表、源行和原始坐标。`data/processed/structures.csv` 共 344 个唯一结构，OPCID/CHIN/CHID 为 68/250/26。参考基因组是 `NC_000913.3`，WT 矩阵来自 [GSE272159](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE272159)。本地可追踪记录见 [data/README.md](../data/README.md)、[configs/data.json](../configs/data.json) 和 [reports/data_audit.json](../reports/data_audit.json)。

本轮已从作者官方下载入口在内存中读取 [Supplementary Tables XLSX](https://media.springernature.com/original/springer-static/esm/art%3A10.1038%2Fs41586-025-09396-y/MediaObjects/41586_2025_9396_MOESM3_ESM.xlsx)，与课程 Excel 逐字节相同：均为 2,698,974 bytes，SHA-256 均为 `a1fa9c0d359509a9eb319442c19e300cb5da85546eeb567368a390d22205167a`，Table 4/5/6 的全部单元格值也分别核对一致。该来源版本对应已证实；未另存重复工作簿。核验记录见 [annotation_source.json](../reports/task1_morphology_annotation_source.json)。

标注坐标的起点和端点约定仍为 `provisional`。原表到 CSV 的数值一致、±1 bp 检查通过及工作簿版本相同，都不能代替来源声明。须保留这个状态，直到有可记录的作者资料或专家确认。历史 `configs/morphology_observations.json` 是人工式描述，不是盲审真值。OPCID 只标代表性子集意味着未标注区域中可能还有 OPCID，但不意味着已标 CHIN/CHID 的模型误判可以改算正确。

## 如何组织审查

建议先由一名熟悉 Micro-C 的审阅者盲审，条件允许时由第二名独立审阅者复核。开始前冻结随机顺序和匿名审查 ID。审阅者第一轮只看目标边界、接触图和数据质量，隐藏原标签、预测、概率、错误分组、结构 ID、基因名和功能轨道。物理坐标和长度用于读图，不伪装去除其生物学含义；另做长度匹配分析。

第二轮才揭示原标签和 CHIN/CHID 嵌套关系，并在需要时核对作者图例及来源。若要核验生物学功能，可另加转录/H-NS/StpA 轨道或相关条件，但必须把“辅助生物学核验”与“只用接触形态的第一轮判断”分别记录。辅助轨道不自动变成训练特征。

审查集合不能只有六例错误。最低覆盖应包括：

1. 全部 26 个 CHID，涵盖持续漏检、持续正确和种子分歧；优先定位 `CHID_8/9/11/12/15/19`，但不事先告诉盲审者哪些是错误。
2. M2+ 在三个种子都判为 CHID 的 CHIN/OPCID 稳定误报，以及 CHIN↔CHID 的跨种子分歧实例。
3. 三类中稳定正确、不同长度和质量的参照，且来自不同空间组；配入与 CHID 长度接近的 CHIN/OPCID，不能只比较典型短 CHIN 与典型长 CHID。
4. 原两组同中心异目标案例 `CHID_18/CHIN_172`、`CHID_25/CHIN_243`，目标边界不同的嵌套实例分别审查，并按空间组统计而非当作独立生物学重复。

随后按同一准则扩展至全 344 个实例；正确参照和错误实例使用相同显示方式。用于形成新外部测试集的新增区域，须先冻结审查准则并隐藏全部模型输出，再进行标注和锁定。

## 每个实例需要看的视图

保留两个 WT 重复各自的图，不先平均。每例显示同样的目标轮廓和基因组轴，并至少比较以下层次：

| 视图 | 要核对的问题 |
| --- | --- |
| 原始 10 bp 局部计数及目标边界 | 原来源能否观察到候选细节；缺失、极稀疏或重复区条带是否被误认成边界 |
| 聚合后的 100 bp 计数，及固定距离背景下的 `log1p(O/E)` | 数值聚合、背景除法和距离屏蔽后是否保留目标内部及跨目标接触关系 |
| 大尺度 25.6 kb 的 256×256 图与实际 64×64 模型视图并排 | 4×4 有效性加权池化是否抹去 CHID 内部细节或改变相对强弱 |
| 小尺度 6.4 kb 实际 64×64 图、有效性通道、目标掩码 | 是否只看见长目标的一部分；是否把旁边/内部 CHIN 当成被分类的目标 |
| 完整目标加固定侧翼的原分辨率图 | 区间边界是否截断结构，是否漏掉域内成员和相邻上下文 |

这组视图是审计输出，不直接替换训练输入。原计数与 O/E 使用各自明确标注的色标；同类视图采用固定、可比较的色标，不逐例自动拉伸造成虚假形态相似。灰色表示缺失或无效，不能与有效零接触混淆。矩阵上下三角是同一接触的镜像，不能算两个独立斑点。

必须记录窗口宽度、显示分辨率、有效面积、目标在窗口内的占比、对角线屏蔽范围及池化因子。模型视图的 O/E 和标准化沿用该案例 fold 的 inner-train 拟合；审计中新展示的全基因组背景视图只能用于描述，不能偷换成已评估的训练协议。保真审查应同时检查本身的数值与图，不凭色彩亮度判断。

## 第一轮可观察准则

下表为项目待验证的操作化审查建议，不是从论文推导的自动判类算法，也不设固定长度阈值。审阅者对每项可填 `present / absent / unclear / unavailable`，并标明支持判断的图和区域。

| 判断 | 需要记录的可观察证据 | 避免误解 |
| --- | --- | --- |
| OPCID 支持度 | 在被指定的目标区间内是否形成相对连续的接触域；目标内部与侧翼的接触差异；边界与重复中的位置是否一致 | 一个亮块、对角线天然增强或由掩码画出的方框本身不能证明 OPCID |
| CHIN 支持度 | 是否存在与同一目标两臂接触相容的局部形态；接触的方向、位置和连续性；两重复能否辨认相近组织；是否有可信的中心/茎与目标端点关系 | 对称镜像不是两个结构；任意孤立亮斑、横纵条带或表 7 的 CHIN 间接触点不能自动当 CHIN |
| CHID 支持度 | 被指定的整个域是否容纳更复杂、可与发卡集合/替代发卡组织相容的接触关系；域的范围和与内部 CHIN 的层级关系；是否仍能在原分辨率及另一重复中辨认 | 长度不是类型定义；可能是群体平均，不要求多个完整发卡在单细胞中同时存在；不能只凭“域内有两条 CHIN 标注”认定图像充分 |
| 质量与边界 | 缺失条带、有效面积、极稀疏区、信号受池化影响、目标端点偏移、目标被截断、旁邻结构占主导 | “图看不清”与“标注错误”是不同结论 |
| 层级与歧义 | 指定区间指向单个结构还是结构域；候选内是否含多个可兼容类别；是否有足够接触证据支持唯一类别 | 目标掩码消除了被问对象的歧义，但不会自动消除生物学类别本身的歧义 |

每例最终允许 `形态支持原类别 / 支持另一类别 / 多种解释均可 / 数据不足`。不强迫把全部实例分成三类。专家需进一步确认哪些具体茎/域边界特征可作为可重复的 CHIN↔CHID 判别依据，以及源标注的实例层级。确认前不把人工提出的候选指标当作已核实的生物学规则。

第二轮揭盲后，再把错误分为：目标/边界歧义、原分辨率可辨但预处理损失、跨重复不稳定、原图质量不足、形态清楚而模型错判、仍无法判定。标注修订只生成新版本和变更理由，保留原标签、坐标、审阅者、证据链接与审查时间；模型多数票不能自动纠错。

## 怎样把形态判断转为模型证据

先固定审查集合与比较方式，再做模型敏感性诊断。目标内部与侧翼遮挡必须匹配有效像素数、距离分布、遮挡形状和幅度；对称地处理矩阵，保留有效性和几何通道，避免把无效零或改变目标面积当成形态破坏。若无法形成有效匹配，记录不可比较，不报告零差值。遮挡可能产生分布外输入，因此只能与其他证据共同解释。

若进行保留覆盖/目标轮廓/长度的纹理扰乱，先验证扰动是否改变接触统计、距离衰减和信号强度；否则不能把模型性能下降单独归因为空间形态。CAM、梯度热图和遮挡结果只说明当前模型对输入的敏感性，不能直接证明其识别了生物学机制。双 WT、长度匹配的正确/错误参照和原图保真证据应共同报告。

在长度匹配子集中报告三类及 CHIN↔CHID 的 TP/FP/FN、macro-F1、重复分歧和种子分歧；不要挑选某个支持预期结论的种子。置信区间如计算应以空间组或新独立样本为重采样单位，不能把两个 WT、三个种子或重叠实例当独立生物学样本。

## 优化与统一复评的边界

六个持续漏检支持优先审查，不足以证明失败由“长度太短”引起；`CHID_11` 为 9.66 kb，与其他五例 3.52–5.25 kb 不同。现有 I3−G0 改回的是接触与有效性共同输入，I3−I0 同时增加掩码与长度；这两项结果不能独立证明模型利用了某种纹理特征或哪一项目标特征起作用。

M2+ 先在已知开发数据上按诊断逐项改动。若问题是池化失真，可先只改变高分辨率目标支路/空间聚合；若问题是训练后期过拟合，可先只验证预登记的 inner 验证权重选择；若问题是边界/类别歧义，应先修订数据协议再重跑，避免靠损失函数掩盖。不要在一个版本同时改分辨率、支路、损失和 checkpoint 规则。

最终四模型（PCA+LR、M2、M2+、CNN-Transformer）须使用相同数据版本、候选定义、输入协议、空间隔离、seed 集合及模型选择预算；神经模型统一头部与学习率等已选训练规则。PCA 也须用新输入重拟合，标准化和 PCA 仅拟合训练部分。几何单独基线继续保留，不能把旧正式分数当作新模型对照。

本轮所有 344 结构的 outer 预测已经读过，用这些错误改输入/模型后，原五折再次运行应称为“开发性统一复评”。换 seed 或重新随机五折不能成为新的盲测。若要声称可靠泛化，应另有从未用于训练、人工错误诊断和方案筛选的空间区域/新标注集或外部样本，冻结最终模型后一次性评估；新区域须与既有模型输入窗口隔离，且审查和标注先于、独立于模型预测。若没有这种资料，明确保留开发性结论，不能凭现有标签重新分组制造独立证据。
