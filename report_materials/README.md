# 实验报告保留材料

本目录是历史写作材料与证据，不是新实验的最终交付。旧任务一明确未达标，其他任务的旧数值也需要在最终报告采用前核对适用范围。

| 材料 | 作用 |
| --- | --- |
| [任务一失败复盘](task1_failure_review.md) | M2 每类表现、种子稳定性和重做原因 |
| [失败复算记录](task1_failure_review.json) | 从保留预测表独立复算的指标与来源 |
| [旧任务一数值记录](../data/legacy_experiments/results/task1/) | 全模型预测、混淆矩阵、评价、训练历史及选模记录 |
| [历史图表](figures/) | 三类矩阵与背景概览、M2 混淆矩阵和解释图、各任务代表性图表 |
| [历史中文说明](legacy_notes/) | 数据准备、读图、实验方法、负结果和候选形态核查 |
| [旧报告 DOCX](历史报告/27_刘小凡_3024244243_旧稿_仅供参考.docx) | 报告结构、封面、文字和历史分析参考 |
| [旧报告独立复算](历史报告/word_polish_verification.json) | 种子一致性、消融与其他任务的补充统计 |
| [报告文献记录](历史报告/word_references_verification.json) | 文献、DOI 和历史核查来源 |
| [旧方法快照](method_snapshot/) | 任务一必要源码、旧配置及训练环境，用于说明旧实验如何产生 |
| [历史审计汇总](../reports/README.md) | 输入和旧数值验证记录 |
| [清理清单](cleanup_manifest.json) | 保留、迁移、删除路径及清理前后 SHA-256 |

旧文档、JSON 和方法快照中的路径保留实验当时的写法；迁移后的对应路径以清理清单的 `retained_path` 为准。方法快照未改造成当前可执行流程。

`data/legacy_experiments/` 保留全部旧结果数值文件，包括包含真实 target/mask 的超分辨矩阵、三维评价输入、局部矩阵、条件信号及候选表。旧缓存和划分保持原样，不能直接等同于重做后的数据集。

`configs/morphology_observations.json` 为历史人工式形态描述；它不是盲法专家标注或训练类别真值。近似宏观域边界等旧配置在方法快照中保留出处，也不能视为已核实标注。
