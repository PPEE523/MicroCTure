# 实验审计与诊断

目录按“任务→实验→版本”组织，保存核对实验完整性、来源、错误与敏感性的JSON/CSV/图；它们与`results/`中的权重、预测、矩阵和坐标用途不同。

- `task1/model_comparison/`与`task1/ablation/`：正式比较、输入/分类头、ROI、原生细节、读出、选权重、融合与dropout的审查。
- `task1/diagnostics/`：标签来源、少数类错误、形态证据与历史分类诊断。
- `task2/`：居中、形态和候选流程核查；NA不写成零异常。
- `shared/`：原始来源/环境审计、三四联合验证和五六保存结果复算。
- `task6/`：三维数据守恒与来源核查。

已删除12份过期操作检查或有完全相同保留副本的JSON；清理路径、大小、SHA和依据保存在`configs/cleanup_20261015.json`。冻结判定、唯一病例明细及科学数值不因文件多而删除。

当前方法、结果与命令只维护[六任务文档](../docs/README.md)。`run.py check`检查精选科学证据、交付和实现；`run.py verify-evidence --all`验证重定位后的原冻结文件。没有恢复旧缺失权重、启动新训练或新增生物学认证。
